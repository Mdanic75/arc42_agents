# Architecture decision records

One file per decision, MADR 4.0, numbered in order of recording: `NNNN-<slug>.md`. A section
worker records one through the `adr` skill the moment a decision surfaces; a person may add one
by hand with the next free number and a row here. The [C4 page](../c4.md) links records from its
tables and under Decisions; arc42 section 9 links this index.
